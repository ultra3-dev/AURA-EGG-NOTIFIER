# AURA EGG NOTIFIER

Script Lua para detectar huevos y enviar alertas al webhook configurado.

## Archivos

- `AURA_EGG_NOTIFIER.lua` — script completo.
- `AURA_EGG_LOADER.lua` — loader corto para ejecutarlo sin pegar todo el código.

## Uso

1. Abre `AURA_EGG_LOADER.lua`.
2. Cambia localmente `PASTE_A_NEW_DISCORD_WEBHOOK_HERE` por un webhook nuevo.
3. Ejecuta únicamente el loader.

El loader descarga `AURA_EGG_NOTIFIER.lua` desde este repositorio. No subas tu copia local configurada con el webhook.

## Seguridad

El webhook que estaba en el archivo adjunto no se publica. Si ese webhook estuvo activo, elimínalo y genera uno nuevo en Discord.
